# Frontend - FC Barcelona API

---

## Tecnologias usadas

    Angular 17
    Bootstrap 5
    TypeScript
    HTML5

Requisitos

    Node.js 18
    Angular instalado

## Instalación y ejecución

Entrar en la carpeta frontend:

cd frontend

## Instalar las dependencias necesarias

npm install bootstrap
npm install

## Ejecutar el servidor de desarrollo

ng serve

## Abrir en el navegador

    http://localhost:4200

Notas

    Tener levantada la consola de mongod y mongo y luego entrar a mongo compass para estar conectado a MongoDB

    Se recomienda tener el backend en ejecución para utilizar todas las funciones.
